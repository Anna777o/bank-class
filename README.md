# Bank Account System

Учебный проект по ООП на Python. Реализует банковскую систему с поддержкой различных статусов счетов и валют.

## Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите демонстрацию: `python src/main.py`
3. Запустите тесты: `pytest tests/`

## Структура
- `src/models.py` — классы счетов (Абстрактный и конкретные).
- `src/utils.py` — исключения и валидаторы.
- `src/main.py` — демонстрация работы.
- `docs/algorithm.md` — описание логики.
