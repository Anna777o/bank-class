# Bank Account System

Учебный проект на Python: объектно-ориентированная банковская система
с риск-анализом, аудитом, отчётностью и графиками.

## Возможности

- **Клиенты и счета**: `Basic`, `Savings` (мин. остаток, проценты),
  `Premium` (овердрафт, комиссия), `Investment` (портфель, прогноз роста).
- **Транзакции**: `deposit`, `withdraw`, `transfer` через очередь с приоритетами
  и отложенным исполнением (`scheduled_at`).
- **Конвертация валют**: RUB, USD, EUR, KZT, CNY.
- **Защита**: 3 попытки входа → блокировка; запрет операций 00:00–05:00;
  запрет переводов при минусе (кроме `Premium`).
- **Риск-анализ**: 4 правила (крупная сумма, частые операции, новый счёт,
  ночь), 3 уровня (`LOW`/`MEDIUM`/`HIGH`), автоматическая блокировка `HIGH`.
- **Аудит**: `AuditLog` в памяти + JSONL-файл, фильтрация по уровню/клиенту/времени.
- **Отчёты**: текстовые, JSON, CSV; графики (круговая, столбчатая, движение баланса).
- **Демонстрация**: 40 транзакций (25 успешных / 2 блокировки / 13 ошибок),
  self-checks, полный отчёт по банку, риску и двум клиентам.

## Требования

- Python ≥ 3.10 (используются `X | None` в аннотациях, `match` в тестах)
- `pytest` для тестов
- `matplotlib` для графиков
